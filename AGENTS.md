# Public BO1VR downloads repository

This repository contains public documentation, support forms and license
notices only. Keep development source, tests, private fixtures, logs and game
assets out. The separate development repository stays PRIVATE.

Public release attachments are the tested portable ZIP, matching SHA256 and
bo1vr-update.json only. Do not upload source archives, PDBs or the setup kit.
Preserve required runtime helper scripts and all dependency notices in the
portable. Native/headset acceptance is separate from CI checks.
